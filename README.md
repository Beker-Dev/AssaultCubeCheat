Install requirements
```bash
pip install -r requirements.txt
```

Compile your .exe and get it from dist/main.exe
```bash
pyinstaller --onefile src/main.py
```

Commands
```bash
/ammo - Activate / Deactivate Infinite Ammo
/health - Activate / Deactivate Infinite Health
/grenade - Activate / Deactivate Infinite Grenades
```

I made this for education porpuses only, use at your own risk.
